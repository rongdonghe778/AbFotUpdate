# CM2206 固件升级

Windows 工具，用来给 CM2206 Dongle 升级 `.fot` 固件，也可以在产线上批量升级，或让 Dongle 进入 DUT。

当前版本：**v1.1.0**。程序界面标题为「CM2206 固件升级」。直接运行 `dist\CM2206.exe`。电脑需要已安装 .NET Framework 4.8。

## 支持的产品

程序按 USB VID/PID 自动识别：

| 产品 | VID | PID |
|---|---|---|
| A7 MAX | 38A6 | 001A |
| A10 | 38A6 | 001D |
| CM2206 | 0D8C | 0352 |

插入后会显示产品名，并填入对应的 VID、PID。列表里没有的设备，可以在产品下拉框里选「自定义」，手动填写 VID 和 PID。

## 普通升级

1. 插入 Dongle。程序启动后会自动查找；没有识别到时，点「查找并连接」。
2. 在「选择固件」里浏览或把 `.fot` 文件拖进窗口。
3. 等「开始升级」变成可点，再点击。
4. 进度到 100%，并提示升级完成、等待设备重启，即这一次升级结束。

升耳机时，Dongle 保持插在电脑上，耳机要用 2.4G 连上这个 Dongle，再选择对应的 `.fot`。

升级过程中不要拔出设备。

## 批量升级

点主界面右上角的「批量升级」，页面会切到批量升级。

1. 先选择固件。
2. 插入一台 Dongle，程序识别后会自动开始升级。
3. 数据传完还不算成功。Dongle 重启并再次被读到，界面显示「升级成功」，这一台才算完成。这次重新连上不会再次升级。
4. 拔出这台。界面变成「请插入下一台」后，再插入下一台，才会开始下一次升级。

同一台 Dongle 会同时出现多路 HID。批量升级只自动连接其中一路，不会弹出设备选择框。

## 产测模式

点「产测模式」，页面会切到产测。

插入并识别到 Dongle 后，程序自动发送进入 DUT 的命令 `47 4D 02 01 01`。Dongle 进入 DUT 后会从电脑上消失，这是正常现象。拔出后再插入下一台，会再次进入 DUT。

右上角「返回升级」回到普通升级页面。

## 其他按钮

- 「USB 设备」：查看或删除系统里留下的 USB VID/PID 记录。删除需要管理员权限。
- 「指令控制」：手动发送 HID 指令，包括进入/退出 DUT、进入/退出 BT 测试、断开 2.4G、搜索设备、读取版本和 GUID。帧格式是 `47 4D` + opcode + length + data。

## 编译

需要 .NET SDK 8 或更高版本：

```powershell
dotnet build AbFotUpdate.csproj -c Release
```

生成的程序在 `dist\CM2206.exe`。
